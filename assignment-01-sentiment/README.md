# Assignment 01: Hinge-Loss Sentiment Classifier

This is the first exercise from the Machine Learning course. It implements a linear sentiment classifier with hinge loss and binary bag-of-words features, covering text preprocessing, feature construction, optimization, and evaluation.

The original run recorded **88.25% test accuracy** on Cornell Review Polarity v2.0.

## Files

- `notebook.ipynb` — the cleaned assignment notebook.
- `README.md` — project summary and setup notes.

## Dataset and usage

Download the dataset from the [Cornell distribution page](https://www.cs.cornell.edu/people/pabo/movie-review-data/) and extract `txt_sentoken/` into this directory. Run `notebook.ipynb` from this directory. The corpus is not included here.
