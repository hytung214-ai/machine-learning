# Multilingual POS Tagging

An English, Chinese, and Japanese part-of-speech tagging experiment comparing a majority-tag baseline, LSTM, and GRU. The original run recorded LSTM token accuracies of 87.97%, 84.59%, and 91.30%, respectively.

Run `notebook.ipynb` from this directory. Its download cells fetch the English EWT, Chinese GSD, and Japanese GSD treebanks from [Universal Dependencies](https://universaldependencies.org/). The downloaded treebanks are not included here. Current upstream data may differ from the version used in the original run.
